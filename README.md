# 東北風土マラソン - コース看板・設置管理アプリ

越後まつだい春の陣で使っている `mow.html` / `arrows.html` と同じ構成（Leaflet + 地理院タイル + Google Apps Script）で作った、東北風土マラソン向けのコース看板・注意喚起・エイド設置ポイント管理アプリです。

ファイル構成:

- `signage.html` — フロントエンド（地図アプリ本体、GitHub Pages等で公開する）
- `Code.gs` — バックエンド（Google Apps Script、Googleスプレッドシートに保存する）
- `README.md` — このファイル

## コースラインについて（GPX不要）

GPXファイルを用意しなくても、アプリ内でコースラインを描けるようにしてあります。

1. ヘッダー右上の **✏️ボタン**（コース描画モード）をタップする
2. 地図を**タップ**していくと、その順番で頂点がつながっていく（下部のツールバーに現在の点数が表示される）
3. 「元に戻す」で直前の点を取り消し、「全消去」で最初からやり直せる
4. 「保存して終了」を押すと、Google スプレッドシートの `course` シートに保存され、以後は全員の画面にそのコースラインが表示される
5. 「キャンセル」を押すと、保存せずに描画モードを終了する（保存済みの内容は変わらない）

保存前にコースが何も登録されていない場合は、長沼フートピア トヨテツの丘公園（宮城県登米市迫町北方字天形161-84）付近を仮表示するラベルだけが出ます。

なお、`signage.html` 内には `COURSE_COORDS_FALLBACK` という配列も残してあります。将来GPXなどからコース座標を抽出できた場合は、ここに入れておくと「まだ誰もコースを描いていない状態」でのデフォルト表示として使えます（普段は空のままでOK）。

## その他、今回のバージョンで「仮」になっている部分

- **カテゴリーは3種類**: 「看板・案内板」「注意喚起（コーン・テープ等）」「エイド・給水」の3カテゴリーで実装しています。矢印（進行方向）を独立したカテゴリーとして分けたい場合は追加できますので、必要であれば教えてください。
- **ポイントの座標は地図長押しで自由に登録**する方式です（`arrows.html` と同じ方式）。あらかじめ座標を決め打ちしたい場合は、そのリストを渡していただければ初期データとして仕込めます。

## セットアップ手順

### 1. Google スプレッドシート + GAS の準備

1. Google スプレッドシートを新規作成する
2. 「拡張機能」→「Apps Script」を開く
3. `Code.gs` の中身をすべて貼り付ける
4. スプレッドシートのURLからIDをコピーし、`Code.gs` 冒頭の

   ```js
   const SHEET_ID = 'ここにスプレッドシートIDを入力';
   ```

   を実際のIDに書き換える（URL: `https://docs.google.com/spreadsheets/d/【ここがID】/edit`）
5. 関数選択で `initializeSheets` を選び、実行する（初回は権限承認のポップアップが出るので許可する）
   - `points` シート・`log` シート・`course` シート（コースライン保存用）が自動生成されます
6. 「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」を選択
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイすると Web アプリの URL が発行されます

### 2. フロントエンド (signage.html) の設定

1. `signage.html` を開き、以下の行を書き換える

   ```js
   const API_URL = 'YOUR_GAS_WEB_APP_URL_HERE';
   ```

   → 手順1で発行された Web アプリの URL に置き換える

### 3. GitHub Pages への公開

自分（Naobumiさん）のGitHubアカウントに新しいリポジトリを作る想定です。リポジトリ名を教えていただければ、こちらでプッシュ〜Pages公開まで進めます。ご自身で進める場合の手順は以下の通りです。

1. GitHub上で新規リポジトリを作成（Public推奨。例: `tfm-signage`）
2. `signage.html` をリポジトリ直下にアップロード（ファイル名は英数字のままでOK）
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branchを `main` / `/(root)` に設定
4. 1〜2分待つと `https://<GitHubユーザー名>.github.io/<リポジトリ名>/signage.html` で公開される

### 4. GASコード更新時の注意

コードだけ更新する場合は「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→ デプロイ（URLは変わりません）。
「新しいデプロイ」を選ぶと新しいURLが発行され、`signage.html` の `API_URL` も更新が必要になります。

## アプリの使い方

- 地図を**長押し**すると、その場所に新しいポイントを追加できます（カテゴリー・名称・担当者を入力）
- マーカーをタップすると、設置状況（未設置／設置済／回収済）・担当者・メモを編集できます
- 右下の「☰」ボタンで一覧パネルを開き、カテゴリー別に絞り込んだり、タップして該当ポイントに地図を移動できます
- 上部のプログレスバーは「設置済＋回収済」の割合を表示します
- 左下に状況別件数、右下にカテゴリー凡例を表示します
